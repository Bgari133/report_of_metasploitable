# Metasploitable Security Assessment Report

This repository contains a Static Application Security Testing (SAST) assessment report for the Metasploitable vulnerable web application environment. The analysis was conducted using Semgrep to identify potential security vulnerabilities, code quality issues, and misconfigurations.

---

## Project Overview

* Target System: Metasploitable Web Application Stack
* Analysis Tool: Semgrep (Static Analysis)
* Objective: Detect critical security vulnerabilities such as SQL Injection (SQLi), Cross-Site Scripting (XSS), Path Traversal, and improper configurations.

---

## Key Findings Summary

| Severity | Vulnerability Type | Primary Location |
| :--- | :--- | :--- |
| High / Critical | SQL Injection | `src/html/payroll_app.php` |
| High / Medium | Reflected / DOM XSS | `src/html/payroll_app.php`, `drupal.sh`, `jquery.form.js` |
| Medium | Path Traversal / SSRF Risks | `drupal.sh`, `password-hash.sh` |
| Low / Info | Insecure HTTP Links | `src/html/phpmyadmin/Documentation.html` |
